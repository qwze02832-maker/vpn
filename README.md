# 🌐 OpenFree

Твой личный и независимый репозиторий для безопасных подписок и конфигураций. Никаких лишних платформ, всё под контролем.

---

## 📂 Мои подписки

Здесь хранятся актуальные конфигурации и ссылки:

* **Основная подписка:** `сюда вставь свою ссылку`
* **Резервный конфиг:** `сюда можно вставить второй ключ, если первый упадет`

---

> 🔒 **Внимание:** Репозиторий приватный, все данные защищены от посторонних глаз.
